# 20261017 展示基线

本版固定保留当前已完成的招新管理功能，供老师及其他访问者了解系统。后续权限增强版将另行开发，不覆盖这一基线的留档。

## 在线展示

[打开展示页面](https://clayallan.github.io/student-union-recruitment/)

页面顶部显示“公开演示 · 20261017 展示基线”，内置60名虚构报名者，数据仅保存在访问者自己的浏览器。可体验报名状态筛选、部门视角、单面和群面排期、面试记录、部门排序、录取匹配、结果导出及通知文本生成。

演示日期随构建调整，方便体验排期；这是公开演示构建处理，不改变协作服务的源文件。短信和微信仍需人员自行发送，系统不自动向外发送消息。请勿导入真实报名信息。

如果页面仍旧，请使用无痕窗口或强制刷新。旧浏览器中的演示数据可能继续保留；需要从样本重新开始时，点击“载入60人演示数据”（会替换该浏览器的演示数据）。

## 代码与版本保留

- 已核对前端及后端12个文件与本地冻结基线一致，校验清单见 [demo-20261017.json](../versions/demo-20261017.json)。
- 功能代码基准是 [c3666c3](https://github.com/ClayAllan/student-union-recruitment/commit/c3666c32b93c2338c73848b223f6a491d5bb5db7)；本次同步补充版本说明和公开演示版本标记，不改写既有业务功能。
- 静态展示使用 `dist/`，协作部署另需 `server/`、SQLite 和服务器配置。GitHub Pages 不运行 Python 后端，不提供正式共享账号登录。
- 需要本地展示，可在仓库选择 Code → Download ZIP，完整解压后打开 `dist/index.html`。本地原始页面不带公开演示构建标记，使用同一套已核对的业务代码。
- 历史提交继续保留，展示基线另以独立分支保存；后续新增版本不得将本基线误标成已实现增强权限的版本。

## 当前协作与拟议增强版

当前协作版提供总负责人和部门负责人账号、服务端部门权限、同步及冲突保护。用户已验证部署环境中的登录、部门可见范围、备注同步、HTTPS、证书模拟续期和备份。

网页新增或停用账号、四级个人岗位、多面试官独立评价、通知任务授权和新的安全措施仍待用户确认并实施。这些能力不能作为本展示版已经具备的功能宣传。

本次同步不上传服务器数据库、真实报名表、账号密码、会话、证书或私钥；不会自动更新腾讯云上的运行服务。
