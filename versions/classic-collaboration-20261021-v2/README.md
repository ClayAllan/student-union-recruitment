# 原版界面账号与任务协作版

版本：`20261021-classic-collaboration-v2`。应用标识`classic-collaboration`，数据库schema为2。技术栈为原版HTML/CSS/JavaScript、Python 3.10以上标准库和SQLite，无额外Python依赖。

本版从`原版登录版_20261021`独立扩展。原业务CSS保留，原版导航、主题、报名、排期、部门记录、排序、录取和通知文本操作继续使用；增加账号管理和任务协作入口。没有覆盖原版登录版、冻结展示基线、原始源码或权限增强版v1/v2。

## 账号与登录

- 岗位顺序：总负责人、主要负责人、负责人、工作人员；岗位和部门分别保存。非总负责人首版绑定一个部门。
- 新密码8—128字符，支持空格、中文和粘贴，拒绝少量常见弱密码；无认证器、手机动态码或公开注册。
- 一个账号最多一个有效登录会话。新登录成功后旧会话失效；错误密码不踢人。相同浏览器配置的多标签和刷新共用会话，不绑定IP或物理设备。
- 会话最长8小时。改密、重置、停用、改部门、岗位或面试资格会撤销旧登录。单会话限制不能证明真人身份，也不能阻止同一令牌被复制。
- 总负责人网页创建账号、修改岗位和状态、重置密码、撤销会话；保留最后一个可用总负责人。敏感管理、导出和恢复需要最近5分钟内再次输入本人密码。
- 临时密码随机16字符、24小时有效、只在创建或重置后显示一次。首次改密后直接进入授权区，无第二次人工激活步骤。本人改密后重新登录。

## 岗位与任务

总负责人统筹全局；主要负责人查看志愿包含本部门的学生并维护本部门业务；负责人和工作人员只见有效任务关联的学生。联系方式按需返回，主要负责人可查看本部门；其他人员必须有有效通知任务。普通面试任务不会返回联系方式或全局内部备注。含联系方式的批量导出先只给总负责人。

三类任务均有执行人、协作人员、截止时间、授权期限、状态和操作记录。截止逾期不等于授权失效。

- **面试任务**从现有排期选人分配。岗位与面试资格分开；有有效任务且获面试资格者填写个人草稿和提交意见。草稿仅本人可读，提交后可由总负责人或本部门主要负责人退回。部门最终记录仍从原版面试记录入口维护，不自动平均个人意见。
- **通知任务**按学生登记待联系、已联系、需跟进，提供模板文本和必要联系方式。由人员在原渠道手动发送，复制不等于已联系。未接入短信、微信或邮件发送。
- **通用待办**不关联学生，不授予报名资料访问权，可记录文字进度和完成要求。部门任务完成后由有权分配者审核；本人私人待办可以直接完成，只有本人可见。首版无附件上传。

主要负责人向本部门负责人或工作人员分配。负责人可从有效上级面试或通知任务中选择“分配给工作人员”，范围和期限不能扩大；无学生的通用待办可直接创建。工作人员不向他人分配。上级授权失效、原安排变化或学生志愿变化后，下级相应授权也失效。

部门显示顺序为办公室、公关部、活动部、权益部、实践部、宣媒部。学生志愿和部门候选排名不会按拼音重排。录取处理顺序与显示次序分开，保持原版三志愿与自动调剂行为；默认名额和场地保持原部门对应值。

## 数据和保存

业务数据存在网站目录外的SQLite中，不写入浏览器localStorage，浏览器只保留主题偏好。旧整份`POST /api/state`写入关闭；原页面适配层提交具体业务操作，后端逐项验证，再在事务中合并。业务使用全局版本保护，任务和个人意见使用独立版本。

冲突或断网时同步栏提示失败，编辑暂留当前页。可在登录和权限仍有效时导出经服务端核对的授权操作草稿，供人工核对，不可当作整库备份恢复。权限范围缩小时以清理无权内容为先，会清掉未提交编辑。

JSON业务恢复通过单独的预览和确认接口执行，事务内保留恢复前业务快照，不回退账号、会话、任务或个人意见；恢复后相关学生任务须重新确认。业务JSON不是整库灾备，正式环境仍应保留SQLite备份。

## 本地启动

从本目录运行，所有测试库放在仓库`99_工作区/`，生产库使用服务器私有目录。包内没有默认运行账号和演示凭据。

```text
python -B server/app.py --db <独立数据库绝对路径> user manager --role admin --name <本人称呼>
python -B server/app.py --db <同一个独立数据库绝对路径> serve --port 8804
```

按终端提示输入自己的密码。先创建总负责人，随后在网页创建个人账号。可信服务器终端也可创建或恢复指定账号：

```text
python -B server/app.py --db <独立数据库绝对路径> user <个人账号> --role lead --department 权益部 --name <本人称呼> --interviewer
```

`user`命令是服务器拥有者的恢复工具，会创建或重置指定个人账号，撤销该账号旧登录；不是批量导入命令。公网使用HTTPS，应用只监听127.0.0.1。

## 原版库副本迁移

只接受原版登录库，不接受权限增强版v1/v2库，也不能把新版本的库接到旧程序。默认不自动启用旧部门共享号，不伪造个人评价作者。

```text
python -B server/migrate_classic.py --source <原版库一致性来源> --target <不存在的新库路径>
```

工具以只读事务检查来源，生成私有来源备份、新库和数量核对报告，不原地修改旧库。来源备份和报告必须保存在私有目录，不上传公开仓库。现有总负责人保留scrypt密码哈希；旧部门账号默认停用、待核实。

如果某旧号已经核实为个人，可私下编写映射JSON，用`--mapping <文件>`明确指定该账号的`verified_individual: true`、`display_name`、`role`、`department`及`can_interview`。部门旧号不能通过映射变成总负责人；未知来源或已存在目标会停止。腾讯云目前的增强版库须另行分析转换，本工具不能直接处理。
