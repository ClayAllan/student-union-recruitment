# 学生会招新协同平台

保留原版页面布局和业务操作的学生会招新内部协作系统，覆盖报名导入、面试排期、评价、部门排序、三志愿录取和通知文案。

## 当前协作版

最新独立版本为 **`20261021-classic-collaboration-v2`**。完整源码位于 [`versions/classic-collaboration-20261021-v2/`](versions/classic-collaboration-20261021-v2/)，使用原版 HTML/CSS/JavaScript、Python 3.10 及以上标准库和 SQLite。

- 账号密码登录，密码长度8—128字符，无认证器或手机动态码。一个账号最多一个有效会话，成功的新登录使旧会话失效；同一浏览器多个标签页共用登录，不绑定物理设备或IP。
- 总负责人、主要负责人、负责人、工作人员四级个人岗位，岗位与所属部门分开。总负责人可在网页创建、调整、停用账号、重置密码和撤销会话。
- 面试任务、通知任务、通用部门待办及私人待办。负责人可在上级授权的范围和期限内再分配；个人面试意见与部门最终记录分开。
- 服务端验证部门、任务、字段权限；SQLite共享保存、版本冲突和会话失效处理。没有学生在线报名或公开注册。
- 保留原版主题、报名、单面/群面排期、部门排序、录取及导出操作。部门按拼音显示，录取处理顺序保留原有行为。

## 主要业务操作

1. 通过Excel、CSV或标准模板导入报名与志愿。
2. 配置部门时段，进行单面、群面排期和冲突检查。
3. 分配面试与通知任务，记录个人意见、部门结论和联系进度。
4. 调整部门候选人排名，按三个志愿、名额及调剂规则生成建议录取结果。
5. 审核录取结果并导出，复制通知文本后在原渠道手动发送。系统不自动发送短信、微信或邮件。

## 数据边界

真实报名信息、联系方式、数据库、运行密码、会话、私钥和本地调试材料不得提交到公开仓库。数据库与备份应保存在私有目录，部署前创建个人账号并检查权限。版本包和自动测试只包含程序与虚构测试向量，不初始化任何生产账号。
